The source prototypes store drafts in the browser and submit to a configured endpoint only when present. The app submits to a real database with anonymity controls. Reproducing source controls must preserve server validation and the existing privacy rules. Before replacing question text or scale meanings, version the questionnaire or otherwise keep historical results identifiable by the scale used.

## Visibility and release implications

- ED Review requires active Canopy or the ED Review add-on; survey creation also requires an assigned Board Chair for the current cycle. The side navigation lists ED Review only for organization owners/admins. An assigned Chair who is a regular member can be authorized for the page yet not see the menu item. This deserves a separate visibility fix and an authenticated non-admin Chair check.
- `origin/staging` contains 194 changed files and seven migrations not present in `origin/main`. Published staging and production both returned HTTP 200 for homepage, `/learning` and health, but production's `/learning` response is not the public course page. HTTP 200 alone is not feature verification.
- The staging deployment is Ready; this review did not apply production migrations or merge code. Production should not be updated until the survey parity and role/navigation gaps are addressed and the production migration/release checks are repeated.

## Correction implemented after the audit

The audit above records what was present in the published staging build at the time of inspection. The follow-up branch `codex/rosalyn-audit-20261113` adds the missing standalone Staff and Partner questionnaires to ED Review. The English source inventory was checked field by field against both HTML files: 18 staff ratings in six sections and 15 partner ratings in four sections, including each question's explanatory text, section guidance, distinct comment prompts, the five-value performance scale, the three partner background fields, review period, deadline, overall prompts and averages. The respondent flow now includes local draft saving, source-key JSON download, Print/PDF, submission, a dated confirmation and a new-response action. French content and a language selector cover the same fields and flow. The organization name and brand color come from the saved brand profile.

The database migration marks new campaigns as instrument version 2. Existing campaigns with responses remain version 1 so old agreement-scale results cannot be silently mixed with the new performance-scale results; existing empty campaigns are upgraded. The anonymous RPC is callable only by the server's service role, after application validation and de-identification. Assigned Board Chairs can see the ED Review menu, and the Committees chair label has the exact punctuation expected by the source.

This correction is scoped to the development Supabase and staging release. It does not change the Olive website or production. The separate externally hosted survey-history limitation in Strategic Planning remains: a metadata-only export from the external service cannot contain responses that were never exported.
