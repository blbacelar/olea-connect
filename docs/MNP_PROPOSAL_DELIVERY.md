## Correction: Board Evaluation and ED Review

I previously called Roots Board Evaluation “missing.” That was wrong. Staging already publishes [Board Self-Evaluation](../app/templates/board-self-evaluation/page.tsx) to Roots and Canopy, with saved template sessions and a PDF export through the [dynamic template editor](../app/templates/template-slug-page.tsx). Its [active seeded form](../supabase/migrations/20260614170000_seed_member_platform_catalog.sql) has a board year, survey period, **one overall rating and one reflection**. A richer 38-question [survey editor](../app/templates/board-self-evaluation/survey-editor.tsx) is present in the repository but the active page does not import it. The new Board Evaluation workspace in this branch is an extension for annual cycles, member responses, aggregate results, and actions; it should not be described as the first board evaluation feature.

[ED Review](../app/modules/ed-review/page.tsx) is also real: it runs an ED/CEO annual review, with assigned reviewers, anonymous staff/partner surveys, and a compiled result. Page 6 of the proposal lists **Board evaluation (Roots)** and **ED/CEO 360 review (Canopy or add-on)** separately. ED Review does not replace the board's self-evaluation. This branch adds the missing server-side Canopy/add-on entitlement check and focused regression tests; an authenticated browser smoke is part of the release gate.
